# Rock-Paper-Scissors
Python Game Project Named Rock Paper Scissors

# Steps
    ## Take the input from the user
    ## Assign a random choice to computer
    ## Compare the user input and computer choice and declare the winner

# Rules
    ## Rock beats Scissors
    ## Scissors beats Paper
    ## Paper beats Rock

# How to run 
    Run the file named 'main.py' then your game will be start !!
